Guía de Instalación del Agente Zebra Tracker360

1. Requisitos Previos (OBLIGATORIOS)

A) Instalar Python: Descargue e instale Python desde python.org. Es obligatorio marcar la casilla "Add Python to PATH" en la primera pantalla del instalador.

B) Configurar Impresora: Vaya a Configuración de Windows > Impresoras. Desmarque la opción "Dejar que Windows administre mi impresora predeterminada" y establezca su impresora Zebra como la predeterminada.

2. Instalación Automática

  1. Extraiga todo el contenido de este archivo ZIP en una carpeta permanente (por ejemplo: C:\Tracker360\). NO mueva ni borre estos archivos después de instalarlos.
  2. Haga clic derecho sobre el archivo instalar_agente.bat y seleccione "Ejecutar como administrador".
  3. Siga las instrucciones en la consola negra. Si todo sale bien, la ventana se cerrará sola y el agente quedará funcionando de forma invisible para siempre.
